# ⏱️ Vibe Timer

Минималистичный кроссплатформенный таймер для автоматического управления питанием системы. Создан для случаев, когда запускается сериал на ночь и система должна сама выключиться по завершении.

## ✨ Основные возможности

### 🎯 Базовый функционал
- **Таймер обратного отсчета** с паузой и отменой
- **5 типов действий:**
  - 💤 Сон (Sleep)
  - 🛌 Гибернация (Hibernate)  
  - 🔴 Выключение (Shutdown)
  - 🔄 Перезагрузка (Restart)
  - 🔄💤 Перезагрузка + Сон
- **Пресеты времени:** 30 мин, 1 ч, 2 ч, 3 ч + кастомное время
- **Система предупреждений:** настраиваемое время (10с, 30с, 1 мин, 2 мин) перед выполнением действия

### 🔔 Оповещения
- 🔊 **Звуковое** — beep-сигнал с настраиваемой громкостью (0-100%)
- 💡 **Световое** — мигание окна (привлечение внимания)
- 🔊💡 **Комбинированное** — звук + световой сигнал
- 🔇 **Беззвучное** — только модальное окно

### 📋 Управление пресетами
- **Создание собственных пресетов** с именами
- **Редактирование** всех параметров пресета
- **Удаление** ненужных пресетов
- **Быстрое применение** сохраненных настроек
- **Автосохранение** в JSON файл

### ⚙️ Настройки приложения
- 🎨 **Прозрачность окна** — регулировка от 30% до 100%
- 🔊 **Громкость по умолчанию** — 0-100%
- 🔔 **Тип оповещения по умолчанию** — звук/световое/оба/без оповещения
- 📌 **Поверх всех окон** — держать приложение всегда видимым
- 📥 **Сворачивание в трей** — минимизация в системный трей
- 🚀 **Запуск свернутым** — старт приложения в фоне

### 💻 Кроссплатформенность
- ✅ **Linux:** Fedora KDE 43, Ubuntu, другие дистрибутивы с systemd
- ✅ **Windows:** Windows 10/11
- **Минимальное потребление:** UI работает в системном WebView (без Electron)
- ✅ **Tauri 2** — актуальная версия фреймворка

### 🎨 Современный дизайн
- Темная тема с градиентами (slate + cyan accent)
- Полупрозрачный фон с blur-эффектом
- Плавные анимации и переходы
- Адаптивная типографика (Inter font)
- Модальные окна для настроек и предупреждений

## 🚀 Установка

### Системные требования

**Общие:**
- Node.js 18+ и npm
- Rust 1.77+ (установка ниже)

**Linux (Fedora/RHEL):**
```bash
sudo dnf install webkit2gtk4.1-devel openssl-devel curl wget file libappindicator-gtk3-devel librsvg2-devel alsa-lib-devel gtk3-devel
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libssl-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev libasound2-dev
```

**Windows:**
- WebView2 (обычно уже установлен в Windows 10/11)
- Visual Studio Build Tools или MinGW

### Установка Rust

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env
```

### Готовые пакеты (без сборки)

Готовые пакеты собираются в локальную папку `release/` (в git не входит):

```bash
npm run package
```

В текущей рабочей копии они уже собраны:

| Файл | Для чего |
|---|---|
| `vibe-timer-0.1.0-x86_64.AppImage` | Linux x86_64, glibc ≥ 2.35; внутри все библиотеки |
| `vibe-timer-0.1.0-1.x86_64.rpm` | Fedora 40+ / RHEL 10 |
| `vibe-timer_0.1.0_amd64.deb` | Ubuntu 22.04+ / Debian 12+ |

Самый простой способ:

```bash
cd release
./install.sh              # установить системный пакет (RPM/DEB)
./install.sh --appimage   # или поставить AppImage только для пользователя
```

Либо вручную (Fedora):

```bash
sudo dnf install ./release/vibe-timer-0.1.0-1.x86_64.rpm
```

После установки приложение появится в меню как **Vibe Timer**. Подробнее —
`release/INSTALL.md` (создаётся командой `npm run package`).

### Совместимость пакетов

Пакеты собраны для **Linux x86_64**. AppImage и DEB собраны на Ubuntu 22.04
и требуют **glibc ≥ 2.35**; RPM собран на Fedora 43 и требует **glibc ≥ 2.39**:

| Система | Статус |
|---|---|
| Fedora 40+ / RHEL 10 | ✅ RPM / AppImage |
| Ubuntu 22.04+ | ✅ DEB / AppImage |
| Debian 12+ | ✅ DEB / AppImage |
| Arch / Manjaro | ✅ AppImage |
| Ubuntu 20.04 / Debian 11 и старше | ❌ glibc < 2.35 |
| Windows 10/11 | ⚠️ собирается в CI (MSI/NSIS) |
| ARM / aarch64 | ❌ не собиралось |
| macOS | ❌ действия питания не реализованы |

Проверить glibc: `ldd --version | head -1`.

Для Windows в репозитории есть `.github/workflows/build.yml`. Запушь
репозиторий на GitHub, открой **Actions → Build packages → Run workflow**
и скачай артефакты:

- `vibe-timer-linux-x86_64` — DEB + AppImage, собранные на Ubuntu 22.04;
- `vibe-timer-windows-x86_64` — MSI и NSIS-установщик (`.exe`).

> Windows-сборка выполняется на `windows-latest`; локально на Linux её
> получить нельзя без отдельного кросс-тулчейна.

## 📖 Руководство пользователя

### Первый запуск

1. **Запустить приложение**
   - Linux: `./vibe-timer` или двойной клик по AppImage
   - Windows: Запустить через меню Пуск или двойной клик по ярлыку

2. **Интерфейс открывается с базовыми настройками**

### Базовое использование

#### Запуск простого таймера

1. **Выбрать время:**
   - Кликнуть по пресету (30 мин, 1 ч, 2 ч, 3 ч)
   - Или ввести свое время в минутах в поле "Своё время"

2. **Выбрать действие:**
   - Открыть выпадающий список "Действие"
   - Выбрать: Сон / Гибернация / Выключение / Перезагрузка / Перезагрузка + Сон

3. **Установить время предупреждения:**
   - Выбрать за сколько секунд показать предупреждение (10с, 30с, 1 мин, 2 мин)

4. **Настроить оповещение:**
   - Выбрать тип: 🔊 Звук / 💡 Световое / 🔊💡 Оба / 🔇 Без оповещения
   - Настроить громкость слайдером (0-100%)

5. **Запустить:** Нажать кнопку **"Запустить таймер"**

#### Во время работы таймера

- **Пауза:** Нажать "⏸ Пауза" (таймер остановится, но не сбросится)
- **Продолжить:** Нажать "▶ Продолжить"
- **Отменить:** Нажать "✕ Отменить" (таймер полностью сбросится)

#### Предупреждение перед действием

За установленное время (например, 30 сек) до выполнения действия:
- Появится **модальное окно** с предупреждением
- Сработает **выбранное оповещение** (звук/световое)
- Кнопка **"Отменить"** позволяет отменить действие

Если не отменить — система выполнит выбранное действие автоматически.

### Работа с пресетами

#### Открыть менеджер пресетов
- Кликнуть по иконке **📋** в правом верхнем углу

#### Создать новый пресет
1. Нажать **"+ Добавить пресет"**
2. Заполнить поля:
   - **Название:** например, "Ночной сериал"
   - **Длительность (минуты):** например, 120
   - **Действие:** Sleep, Shutdown и т.д.
   - **Предупреждение (сек):** 10-120
   - **Оповещение:** тип оповещения
   - **Громкость:** 0-100%
3. Нажать **"Сохранить"**

#### Применить пресет
- Кликнуть **"Применить"** на карточке пресета
- Все параметры автоматически подставятся в главное окно

#### Редактировать пресет
1. Нажать иконку **✏️** на карточке пресета
2. Изменить нужные поля
3. Нажать **"Сохранить"**

#### Удалить пресет
- Нажать иконку **🗑️** на карточке пресета
- Подтвердить удаление

**Пресеты сохраняются автоматически** в файл `presets.json` в директории данных приложения.

### Настройки приложения

#### Открыть настройки
- Кликнуть по иконке **⚙️** в правом верхнем углу

#### Прозрачность окна
- Слайдер **"Прозрачность окна"** (30-100%)
- Изменение применяется сразу после сохранения

#### Громкость звука
- Слайдер **"Громкость звука"** (0-100%)
- Применяется как значение по умолчанию для новых таймеров

#### Тип оповещения по умолчанию
- Выпадающий список: Звук / Световое / Оба / Без оповещения
- Кнопка **"Протестировать"** — проверить выбранное оповещение

#### Чекбоксы
- ☑️ **Поверх всех окон** — окно всегда видно
- ☑️ **Сворачивать в системный трей** — минимизация в трей
- ☑️ **Запускать свернутым** — старт в фоне

#### Сохранить настройки
- Нажать **"Сохранить"**
- Настройки применятся и сохранятся в `settings.json`

### Системный трей

При закрытии окна приложение остаётся в системном трее (область уведомлений), если включена настройка **«Сворачивать в системный трей»**. Чтобы завершить приложение полностью, используйте пункт **«Выход»** в меню трея.

**Действия в трее:**
- Клик по иконке — открыть меню (поведение зависит от окружения; в KDE/GNOME меню открывается кликом)
- **Показать** — открыть окно
- **Скрыть** — скрыть окно
- **Выход** — закрыть приложение

## ⚠️ Важные замечания

### Linux (systemd)

**Требуются права для системных команд:**

Команды `systemctl suspend/hibernate/poweroff/reboot` могут требовать sudo.

**Решение через polkit:**

Создать файл `/etc/polkit-1/rules.d/10-vibe-timer.rules`:

```javascript
polkit.addRule(function(action, subject) {
    if ((action.id == "org.freedesktop.login1.suspend" ||
         action.id == "org.freedesktop.login1.hibernate" ||
         action.id == "org.freedesktop.login1.power-off" ||
         action.id == "org.freedesktop.login1.reboot") &&
        subject.isInGroup("wheel")) {
        return polkit.Result.YES;
    }
});
```

Перезагрузить polkit:
```bash
sudo systemctl restart polkit
```

### Windows

**UAC (User Account Control):**

Команды `shutdown.exe` могут требовать прав администратора.

**Решение:**
- Запускать приложение от имени администратора
- Или отключить UAC для конкретных команд через Group Policy

## 🐛 Известные проблемы

1. **Прозрачность окна на Linux**
   - Реализована через CSS-переменную и `transparent: true` окна
   - Требует работающего композитора (KDE/GNOME — ок)
   - На некоторых Wayland-конфигурациях прозрачность может отличаться

2. **Звуковые оповещения требуют ALSA/PulseAudio (Linux)**
   - Установить `alsa-lib-devel` или `libasound2-dev`

3. **«Перезагрузка + Сон»**
   - Linux: создаётся временный systemd user unit, который после следующего
     входа в сеанс усыпляет систему и удаляется
   - Windows: используется RunOnce-запись в реестре текущего пользователя
   - В обоих случаях после перезагрузки требуется вход пользователя в систему

4. **Системные команды питания**
   - Linux: могут требовать polkit-разрешений (см. ниже)
   - Windows: могут требовать прав администратора
